# Vitrine

A native PS5 app: a shelf of 3D game cases, one tab per platform, with real box art and your emulator libraries,
for a jailbroken PS5 (title ID **PPSA99850**). Written in C++ and OpenGL.

Vitrine is **based on [Boxshelf](https://github.com/sassiestrhihno/boxshelf-source)** by sassiestrhihno (GPL-3.0): its
design, case styles and library rules were studied and re-implemented for the PS5. Vitrine is **not** the official
Boxshelf and is not affiliated with it; it has its own name and icon, as Boxshelf's author asks of forks.

- **Install and use:** [`ps5/README.md`](ps5/README.md). Downloads: the [latest release](../../releases/latest).
- **Source of the app:** [`ps5/`](ps5/).
- **Boxshelf's own sources** (Windows / Android / Linux) stay in the other folders of this repository, untouched, as the
  reference the port is measured against. Boxshelf's original README is kept as
  [`docs/BOXSHELF-README.md`](docs/BOXSHELF-README.md).
- **Project notes:** [`PS5-PORT.md`](PS5-PORT.md) (the brief) and [`PROGRESS.md`](PROGRESS.md) (the log).
